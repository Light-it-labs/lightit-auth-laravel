## 1. Treat 419 as a final status in `src/config/query-client.ts`

That file is shared with every other query in the app, so it was left untouched.
Apply the change by hand. Declare the constant below the existing imports:

```ts
const CSRF_TOKEN_MISMATCH = 419;
```

Then add it to the list of statuses that are never retried, inside
`defaultOptions.queries.retry`:

```ts
      retry: (failureCount, error) => {
        return error instanceof ZodError ||
          (isAxiosError(error) &&
            error.response?.status &&
            [
              HttpStatusCode.Unauthorized,
              HttpStatusCode.Forbidden,
              HttpStatusCode.NotFound,
              CSRF_TOKEN_MISMATCH,
            ].includes(error.response.status))
          ? false
          : failureCount <= 3;
      },
```

Without it a stale cookie turns into three retried requests before the redirect
to `/login` fires.
